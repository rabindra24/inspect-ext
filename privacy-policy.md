# Privacy Policy — CSS Inspector & Live Editor

**Last updated:** October 20, 2026

## Overview

CSS Inspector & Live Editor is a Chrome extension that helps developers inspect webpage elements, edit CSS styles in real time, preview changes, and copy CSS code.

## Information Access

The extension accesses webpage elements and CSS styles when users invoke its inspection and editing features. This access is used to provide the extension's core functionality.

## Data Collection and Sharing

The extension's collection, storage, and sharing practices depend on its actual implementation. Any personal information or webpage content collected or transmitted outside the browser must be disclosed accurately.

## Data Usage

Information accessed by the extension is used only for its stated functionality, subject to the extension's actual data practices.

## Data Security

Reasonable measures should be taken to protect any information collected or stored by the extension.

## Changes to This Policy

This policy may be updated when the extension's functionality or data practices change.

## Contact

For questions about this policy, contact the extension developer through the contact information provided on the Chrome Web Store listing.
